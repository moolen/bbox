# Phase 3 TLS MITM Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add manager-wide TLS MITM with ephemeral CA generation, sandbox trust injection, decrypted HTTPS request policy enforcement, and HTTP/1.1 plus HTTP/2 interception with multi-stream correctness coverage.

**Architecture:** Keep the sandbox-local helper as the ingress point and TLS terminator, while the host-side `ProxyManager` remains the only outbound dialer and the single policy authority. MITM is opt-in per manager, uses an ephemeral in-memory CA, injects trust into staged sandbox roots, forwards decrypted requests over an extended helper protocol, and preserves raw CONNECT tunneling when MITM is disabled.

**Tech Stack:** Go, bubblewrap, Go standard library `crypto/tls` and `net/http`, `x/net/http2` as needed, existing gob-based helper bridge
